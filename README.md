# Sahil.top - Premium Developer Portfolio & Digital Agency

A modern, high-performance, and conversion-focused website built for **Sahil Jangra**. This project combines a personal developer portfolio with a professional digital agency presence, optimized for client acquisition and brand building.

## 🚀 Live Demo
Visit: [technologia-ashen.vercel.app](https://technologia-ashen.vercel.app)

## ✨ Features
- **Modern UI/UX**: Dark theme with premium glassmorphism, smooth animations, and advanced typography (Plus Jakarta Sans & Space Grotesk).
- **Floating Navigation**: A sleek, modern "Bottom-Pill" floating navigation bar for better reachability.
- **Article Management System**: 
    - Dedicated blog section with a premium grid layout.
    - **Article File Maker**: A custom-built internal tool to generate and download new article pages with consistent styling and full SEO support.
- **Complete SEO & Social Support**:
    - **Meta Tags**: Fully optimized title, description, and keywords for each page.
    - **Open Graph & Twitter Cards**: High-quality social previews for WhatsApp, Facebook, and Twitter.
    - **JSON-LD Schema**: Structured data for professional services and search engine indexing.
- **Responsive Design**: Mobile-first architecture with specific fixes for tech logos, hero sections, and forms.
- **Interactive Elements**: Scroll-reveal animations, spotlight hover effects, FAQ toggles, and real-time local time integration.
- **Conversion Focused**: Professional services grid, transparent pricing tiers, and a detailed lead-generation form with 100+ country support and project-specific topics.

## 🛠️ Tech Stack
- **HTML5**: Semantic structure for maximum accessibility and SEO.
- **Tailwind CSS**: Utility-first styling with custom glassmorphism and typography plugins.
- **Vanilla JavaScript**: Lightweight, framework-free interactions, Blob API for file generation, and smooth animations.
- **Font Awesome**: Premium iconography suite.
