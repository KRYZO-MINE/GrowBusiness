# Sahil.top - Premium Developer Portfolio & Digital Agency

A modern, high-performance, and conversion-focused website built for **Sahil Jangra**. This project combines a personal developer portfolio with a professional digital agency presence, optimized for client acquisition and brand building.

## 🚀 Live Demo
Visit: [sahil.top](https://sahil.top)

## ✨ Features
- **Modern UI/UX**: Dark theme with glassmorphism, smooth animations, and premium typography.
- **Floating Navigation**: A sleek, modern bottom-pill navigation bar.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Article System**: A dedicated articles/blog section with SEO-friendly meta tags and social sharing optimization.
- **Interactive Elements**: Scroll-reveal animations, spotlight hover effects, and real-time clock integration.
- **Conversion Focused**: Professional services grid, transparent pricing, and a detailed contact form with budget/topic selection.
- **Performance Optimized**: Fast load times with asset preloading and clean vanilla code.

## 🛠️ Tech Stack
- **HTML5**: Semantic structure for SEO.
- **Tailwind CSS**: Utility-first styling for rapid, premium design.
- **Vanilla JavaScript**: Lightweight, framework-free interactions and animations.
- **Font Awesome**: Premium iconography.
